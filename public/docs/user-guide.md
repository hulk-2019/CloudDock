# CloudDock 使用手册

欢迎使用 CloudDock！这是一款支持多云厂商的浏览器云存储管理插件。

## 快速开始

### 1. 配置云存储

1. 点击浏览器工具栏的 CloudDock 图标
2. 点击"设置"进入配置页面
3. 选择你的云存储厂商（阿里云 OSS、腾讯云 COS、七牛云、AWS S3）
4. 填写 Access Key ID 和 Secret
5. 填写 Region 和 Bucket 名称
6. 点击"保存配置"

### 2. 打开云盘

有三种方式打开云盘：

- **方式1**：点击页面右下角的悬浮按钮
- **方式2**：点击浏览器工具栏图标 → "打开云盘"
- **方式3**：右键悬浮按钮 → "打开云盘"

### 3. 上传文件

支持多种上传方式：

#### 拖拽本地文件
直接将电脑上的文件拖拽到抽屉区域即可上传

#### 拖拽网页图片/视频
在网页中找到图片或视频，直接拖拽到抽屉区域，CloudDock 会自动下载并上传到你的云存储

#### 截图粘贴上传
1. 使用系统截图工具截图（如 macOS 的 Cmd+Shift+4、Windows 的 Win+Shift+S）
2. 在抽屉区域按 `Ctrl+V`（macOS: `Cmd+V`）粘贴
3. 截图会自动上传到当前目录

### 4. 文件管理

#### 浏览文件
- 点击文件夹进入子目录
- 使用面包屑导航快速跳转

#### 复制文件链接
点击文件，会自动复制文件的访问链接到剪贴板

#### 删除文件
点击文件右侧的删除按钮，确认后删除

#### 新建文件夹
点击顶部的文件夹加号图标，输入文件夹名称创建

## 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+V` | 粘贴截图上传（需要在抽屉区域） |

## 常见问题

### Q: 配置后无法连接云存储？
A: 请检查：
1. Access Key 是否正确
2. Region 格式是否正确（不同厂商格式不同）
3. Bucket 是否存在且有读写权限
4. 网络连接是否正常

### Q: 上传大文件很慢？
A: 上传速度取决于：
1. 你的网络上行带宽
2. 云厂商服务器位置（选择就近的 Region）
3. 文件大小（超大文件建议使用云厂商的桌面客户端）

### Q: AK/SK 安全吗？
A: CloudDock 使用 AES-256 加密算法将你的凭证加密后存储在浏览器本地，不会发送到任何第三方服务器。

### Q: 支持哪些文件格式？
A: 支持所有文件格式，没有限制。

### Q: 可以同时管理多个 Bucket 吗？
A: 当前版本只支持配置一个 Bucket。如需切换，请到配置页面修改。
